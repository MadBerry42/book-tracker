# book-tracker
A simple web-based book tracker which uses the Google Books API to find book info.

The codes have been written in python using the open-source Streamlit library to create the web app.
Here's the library documentation https://docs.streamlit.io/get-started/fundamentals

This code is still in the development phase and has not been deployed yet. Feel free to take a look anyway and maybe take some inspiration for your own project!
